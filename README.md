# 提示词与视频网站初版

前端和后端在同一个项目。运行时使用 Go 服务，HTML、CSS、JavaScript 直接编进同一个程序；SQLite 保存只读检索索引。`build_index.py` 是离线索引工具，从当前项目已验收清单更新数据，不参与线上请求。

## 本地运行

在项目根目录执行：

```sh
python3 prompt-web/build_index.py
cd prompt-web
go run . --port 18766
```

打开 http://127.0.0.1:18766/ 。服务只监听本机。素材清单更新后重新运行索引工具并重启服务即可；索引不会复制视频文件。

## 技术方案

- 原生前端，无前端框架、外部字体和前端构建服务。
- Go 单进程负责页面和检索；SQLite FTS5 建立英文与中文搜索索引，单页最多 24 条。
- 列表只返回摘要与媒体路径；点击封面时才加载视频，在卡片内直接播放。点击“查看并复制提示词”才请求完整中文提示词，浮层内可直接复制。有原始输入图的案例也在浮层内展示。页面和详情接口不展示原提示词与来源出处。
- 已验收的媒体按 `v1/cases/<案例ID>/video.mp4`、`poster.jpg`、`inputs/image-01.png` 等路径存入 R2 的 `osh-prompt` 桶；实际扩展名保留原文件格式。`upload_r2.py` 可重复运行，跳过远端长度及 SHA-256 元数据一致的文件。
- 有原始参考图的案例可在浏览器中将完整中文提示词与参考图打成 ZIP；图片通过私有 R2 的短时签名链接直接下载到浏览器，服务端不传输图片字节。桶 CORS 仅允许 `https://prompt.osh.lol` 发起 GET。只有提示词的案例下载 TXT。生成时的原始音色/输入音频尚未收录，成片音轨只随视频试听，不加入素材包。
- 列表提供“有参考图”和“缺少参考素材”筛选；带图案例在卡片直接显示原始参考图缩略图，可打开提示词浮层并查看大图。视频时长显示到 0.1 秒，可按不足 10 秒、10–19.9 秒、20–29.9 秒和 30 秒以上筛选。
- R2 存储桶保持私有。生产环境为 Go 服务配置仅能读取 `osh-prompt` 的 S3 凭据；浏览器请求 `/media/...` 时，Go 服务返回临时签名地址的 302 跳转。图片地址有效 15 分钟，视频地址有效 1 小时，每次从站点请求都会重新签发。浏览器直接从 Cloudflare R2 读取媒体，Go 服务不转发媒体字节，因此不占用服务器的媒体存储或出口带宽。公开页面上的访客仍能播放和保存展示的视频，后续接入账户与积分时可在签发前增加权限判断。
- 服务器使用已有 Nginx 反向代理。桶只放已验收媒体，后台清单和待核验素材不上传。

批量上传前，从 Cloudflare 创建仅限 `osh-prompt` 的对象读写令牌，把 S3 密钥放在本机临时凭据文件中，再运行 `python upload_r2.py --credentials-file <文件>`。令牌和凭据文件不可加入项目或 Git。

未来支付、积分和账户功能可继续加在 Go 服务中，以独立业务表和交易记录实现。初版没有这些功能，也没有任何收款入口。

## 独立图片图库

`/images` 是图片与提示词图库，和视频案例分开。`build_images_index.py` 从 DiffusionDB、Qwen Image Bench、GPT Image 2 社区案例的本地只读数据库生成索引，不修改源文件。当前索引为 109,661 张图片，其中 35,040 张已有中文提示词；其余原始提示词保存在索引中供后续翻译，网页接口不返回原文。

缩略图和原图分别按 `v1/images/<图库>/<图片ID>/thumb.webp` 与 `original.<原扩展名>` 上传至私有 R2。`upload_images_r2.py` 记录每个已上传且回读核验成功的对象，失败后可继续运行。`build_published_images.py` 只把缩略图和原图都已核验的图片编入线上索引，因此网站不会列出缺失媒体的图片。浏览器通过临时签名链接直接从 R2 获取图片；打包下载在浏览器完成，不经过服务器媒体出口。

批量上传期间，本机的 `com.osh.prompt-images-upload` LaunchAgent 继续传输，`com.osh.prompt-images-publish` 每五分钟把已核验图片同步到网站。上传凭证只保存在本机 `/tmp/prompt-osh-private/r2-upload.json`，有效期 30 天，权限仅限 `osh-prompt` 桶对象读写；不得提交到 Git。上传完成后可停用任务并删除临时凭证。
