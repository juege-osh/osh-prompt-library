# OSH 灵感库

接手开发和上线请看 [部署与重启手册](DEPLOY.md)，本地配置和接口约定见 [LOCAL_ACCESS.md](LOCAL_ACCESS.md)。

前端和后端在同一个项目。运行时使用 Go 服务，HTML、CSS、JavaScript、Lucide 和 Chart.js 直接编进同一个程序。`catalog.sqlite3` 和 `images_catalog.sqlite3` 是只读资源索引；独立的 `app.sqlite3` 保存用户、会员、积分、订单和已购资产。`build_index.py` 是离线索引工具，不参与线上请求。

## 账户与积分

- 导航分为创作、资产、用户中心、会员中心；控制台仅管理员可见。
- 角色为普通用户 `normal=1`、VIP `vip=2`、管理员 `admin=3`。第一个注册用户不会自动成为管理员。
- 注册通过邮箱验证码赠送 888 充值积分，长期有效。登录使用 HttpOnly Cookie 和 SQLite 会话，不依赖 Redis。
- 月/年/永久 VIP 套餐价格为 8.8/88/188 元，每月分别发放 1288/1888/3888 额度，仅当期有效；升级套餐补充当期额度。
- 充值积分和会员额度按批次及流水分开记录，消费优先使用即将过期批次。积分支持两位小数，数据库以百分之一积分为整数单位记账。
- 视频提示词基础价格为 5 积分，图片为 1 积分；实际扣费为基础价格乘管理员设置的 0.10-1.00 倍率。同一用户同一资源只扣费一次，已购资产持续可用；管理员免扣费。
- 游客可浏览封面和压缩预览；提示词、视频播放、原图和下载需要登录并解锁。VIP 同样需要使用积分购买资源。
- 用户中心支持修改密码/邮箱、注销账号、订单记录、额度进度条、视频/图片购买占比和最近最多 10 天的消费统计。注销使用逻辑删除，保留业务记录。
- 管理员可检索用户、查看详情、手动发放会员/调整积分、拉黑/解封用户及设置扣费倍率。
- 邮箱验证码用于注册、忘记密码和修改邮箱，使用 TLS SMTP 真实发送；有过期、限流和尝试次数限制，不向浏览器返回明文验证码。

**真实支付尚未接入，充值和会员购买入口暂不可付款。** 当前会员及充值积分可由管理员手动发放，订单记录不代表已对接支付网关。

## 本地运行

需要 Go 1.26.4 或更新版本。本仓库只保存代码，视频、图片、各 SQLite 数据库和真实密钥都不在 GitHub 中。将已发布的两个资源索引放入项目目录，参考 `.env.example` 配置本地 `.env`，然后运行：

```sh
go run . --port 18766
```

打开 http://127.0.0.1:18766/ 。服务只监听本机，自动创建或迁移 `app.sqlite3`；可通过 `--app-db` 指定独立路径。前端文件已嵌入程序，修改后必须重新编译或重启 `go run`。R2 只读凭证用于读取媒体，SMTP 授权码用于发送验证码，均只保存在本地环境配置中。

只有需要从源素材重建索引时，才将仓库作为素材目录中的 `prompt-web`，从素材根目录运行 `python3 prompt-web/build_index.py` 和 `python3 prompt-web/build_images_index.py`。仅克隆此代码仓库无法重建资源数据。

## 技术方案

- 原生前端，无前端框架、外部字体和前端构建服务。
- Go 单进程负责页面、检索、账户、会员和积分；SQLite FTS5 建立英文与中文搜索索引，单页最多 24 条。
- 列表只返回摘要和受控媒体路径；购买资源后可查看/复制提示词、播放视频或查看原图，并将提示词与可用媒体打包下载。未购买的资源不会返回完整提示词或原始媒体。
- 已验收的媒体按 `v1/cases/<案例ID>/video.mp4`、`poster.jpg`、`inputs/image-01.png` 等路径存入 R2 的 `osh-prompt` 桶；实际扩展名保留原文件格式。`upload_r2.py` 可重复运行，跳过远端长度及 SHA-256 元数据一致的文件。
- 资产 ZIP 在浏览器中生成，包含提示词及可用的视频/参考图或原图；媒体经本站鉴权接口读取。生成时的原始音色/输入音频尚未收录，成片音轨随视频保存。
- 列表提供“有参考图”和“缺少参考素材”筛选；带图案例在卡片直接显示原始参考图缩略图，可打开提示词浮层并查看大图。视频时长显示到 0.1 秒，可按不足 10 秒、10–19.9 秒、20–29.9 秒和 30 秒以上筛选。
- R2 存储桶保持私有。生产环境为 Go 服务配置仅能读取 `osh-prompt` 的 S3 凭据；Go 对受保护媒体进行权限检查，并从 R2 流式转发，支持 Range 视频请求。不再向浏览器暴露签名地址或返回 302 跳转，媒体会占用服务器出口带宽。受保护响应为 `private, no-store`，Nginx/CDN 不得缓存这些响应。
- 服务器使用已有 Nginx 反向代理。桶只放已验收媒体，后台清单和待核验素材不上传。

批量上传前，从 Cloudflare 创建仅限 `osh-prompt` 的对象读写令牌，把 S3 密钥放在本机临时凭据文件中，再运行 `python upload_r2.py --credentials-file <文件>`。令牌和凭据文件不可加入项目或 Git。

数据库备份、升级与权限要求见部署手册。不要把本地空的 `app.sqlite3` 覆盖到已有业务数据的服务器上，也不要用旧版整数积分程序打开已迁移的小数积分数据库。

## 独立图片图库

`/images` 是图片与提示词图库，和视频案例分开。`build_images_index.py` 从 DiffusionDB、Qwen Image Bench、GPT Image 2 社区案例的本地只读数据库生成索引，不修改源文件。素材和翻译数量持续变化，以线上已发布索引为准。购买后优先展示中文提示词，没有中文译文时使用原始提示词。

缩略图和原图分别按 `v1/images/<图库>/<图片ID>/thumb.webp` 与 `original.<原扩展名>` 上传至私有 R2。`upload_images_r2.py` 记录每个已上传且回读核验成功的对象，失败后可继续运行。`build_published_images.py` 只把缩略图和原图都已核验的图片编入线上索引。缩略图可公开浏览，原图通过本站鉴权后由 Go 转发；打包下载在浏览器完成。

批量上传期间，本机的 `com.osh.prompt-images-upload` LaunchAgent 继续传输，`com.osh.prompt-images-publish` 每五分钟把已核验图片同步到网站。上传凭证只保存在本机 `/tmp/prompt-osh-private/r2-upload.json`，有效期 30 天，权限仅限 `osh-prompt` 桶对象读写；不得提交到 Git。上传完成后可停用任务并删除临时凭证。
